远程 Agent 邮局 MCP

让不同电脑、不同软件里的 Agent，像打电话一样互相发话、互相查看近况。人在网页开号，Agent 用绑定码占用这个号。

01结论：可行，做成邮局，不要做成电话交换机

方案可行。 服务器上跑一个 MCP（Agent 用的工具插头），网页给人开号。Agent 注册后，用对方的「通讯码」发消息、读对方近期发言——对应 Ensemble 本机已经有的 peer_send 和 peer_query。

必须能自动多轮。 做法是 MCP 提供长轮询工具 inbox_wait（和 Ensemble 已有的 job_wait 同类：这一轮先不结束，挂在工具上等到有信或超时）。服务器自己空转查信箱叫醒不了闲着的窗口——轮询必须发生在Agent 已经打开的这一轮里。

身份证 · ID

系统内部编号。一个人一个，不给别人看、不能改。

电话号码 · 通讯码

公开给别人打你。可以写在纸上、发给同事。

SIM 卡 PIN · 绑定码

只有拿到这串码的 Agent 能占用这个号。用一次（或直到你重置）。保密。

网页再填一个名称（名片上的名字，方便人认，不保证全球不重名）。通讯靠通讯码，不靠名字。

注册规则：一个 ID 同时只给一个在线 Agent。已占用再拿同一绑定码注册 → 拒绝。掉线后允许原绑定码重新占用（像拔掉网线再插上）。换一台电脑占用：你在网页点「重置绑定码」，旧码作废。

MCP 注册成功后必须用白话告诉 Agent：你的名字和通讯码是什么、怎么给别人发、怎么查信箱、绑定码不要写进回复里。工具说明本身就是说明书，不必另做一本手册给模型。

03自动多轮：在 MCP 里长轮询，不要只空查信箱

可以。轮询加在 MCP 工具里，不是服务器在后台空转。Agent 发完信调用 inbox_wait(最多等 N 秒)：有信立刻返回，没信就挂着。对方一投递，这边这一轮还在，拆信、回复、再 wait——乒乓自动转。和本机等任务结束的 job_wait 同一类。

人各点一次
开始（两边都要）
→
A send
然后 inbox_wait
信到
B 正在 wait
醒来 → 回复 → wait
信到
A 醒来
直到双方说完
轮询能做什么、不能做什么 服务器自己 while 查数据库，客户端没在跑工具 → 窗口仍是闲的，等于没轮询。长轮询只服务「这一轮已经开始」的人。因此人仍须两边都点一次开始（或一边先开口、一边已经 wait）。之后不必每轮都靠人按回车。超时（建议上限 60–120 秒，可连 wait）后工具返回「暂无新信」；说明书要求再 wait，或外面包 Ensemble Loop 当保险，防止模型忘了续。

「投递即叫醒」（邮局通知 Ensemble 自动新开一轮）能叫醒完全闲着的窗口，要改客户端、验身份，作第二步，不是替代 inbox_wait。

文件像信封里的附件，不另开一条网盘。发信时可带上文件（代码、图片、小压缩包）。邮局代存，收件人用 file_get 取走。上限建议单文件 20MB、一封信几个附件；过期自动删（如 7 天）。只许收件人取，别人拿编号也取不到。说明书：需要对方看文件时用附件，不要把整份文件糊进聊天正文。

和本机 peer 不要混为一谈 同一台 Ensemble 里的 Agent 继续用原来的 peer_send。这个 MCP 解决的是跨机器、跨软件（例如家里一台、公司一台，或 Claude 和 Ensemble 各一个）。通讯码打不到本机树里那个 UUID，两套地址不要混用。

05网上已有什么，我们抄哪一层

项目像什么对我们
Agent Junction局域网上的 MCP 对讲机：注册、列表、发信、读信最像。我们补上网页开号 + 绑定码 + 部署到公网。
agents-mailbox · mailbox-mcp同一台电脑共享文件夹当信箱不能给「用户各自在自己电脑」用。
agentbus本机「把信塞进正在跑的窗口」叫醒问题写得很清楚；那是客户端的事，不是第一版服务器的事。
A2A（原 Google，现 Linux 基金会；IBM ACP 已并入）Agent 当网站互相调用的行业标准太重。MCP 是「给一个 Agent 工具」；A2A 是「Agent 当服务」。第一版用 MCP 邮局即可，以后要对接外面生态再加 A2A 门牌。

官方也说：MCP 管工具，A2A 管 Agent 与 Agent。用 MCP 做邮局是借工具通道传信，业界有成例，不是歪路。不要第一版就宣称「我们兼容 A2A」。

06第一版做这些，别做那些

做

  • 网页：起名、生成三码、重置绑定、吊销号
  • MCP：注册、发信、附件、inbox、inbox_wait、query、whoami
  • 说明书写死：发完必须 wait，直到目标完成
  • HTTPS + 绑定码；一号同时一人

不做（第一版）

  • 只在服务器空转查库却不挂工具（假轮询）
  • 投递即叫醒留第二步
  • 不限大小的网盘、直播流、可执行文件当默认可跑（只当附件存）
  • 通讯录公开广场（避免被扫号）
  • 冒充 Ensemble 本机的团队边界（远程另有一份「谁能打谁」，默认：知道通讯码就能发，可选加「必须互加好友」）

安全底线：绑定码只显示一次、可重置；通讯码不要当密码；附件只给收件人、带校验哈希、过期删除；日志不写绑定码。

用户怎么接到 Ensemble：在 Agent 设置里加一条远程 MCP（网页上复制地址）。三个运行时（Claude / OpenAI / Codex）都能挂 HTTP MCP，这是现成能力，不必改内核协议。

审核结论：自动多轮 = 邮局送信 + MCP 长轮询挂住回合。两边先各开一轮。同类开源里 Agent Junction 最近。文档供拍板，不是实现说明书。
